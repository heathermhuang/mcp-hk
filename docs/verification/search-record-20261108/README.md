# Search ranking and query-to-record journey

The shared search service now merges guided services and native datasets by the same deterministic relevance contract before pagination. Exact names/IDs, reviewed task aliases, titles, providers and description-only matches have distinct buckets. The generic catalogue gateway follows subject matches unless the query explicitly requests the catalogue. Title collation and the empty-query API overview retain their previous ordering.

SQLite calls the same pure rank primitives as the guided stream, and returns at most `limit + matching connected entries` native payloads. Only the final page receives capability/resource-summary enrichment. There is no index, model, source query or persistent ranking cache. NFKC/casefold normalization now also applies inside native candidate matching; fullwidth and repeated-whitespace regressions cover that correction. Literal `%` and `_` retain literal matching.

The reviewed HKO task overlay adds `weather`, `current weather`, `天氣` and `現時天氣` to the already qualified current-weather dataset. Its original metadata has no Chinese title. `天氣` therefore gains one matching native dataset (12 to 13 overall); weather/school/學校 totals stay 37/106/17 in the saved corpus. This changes discovery, not source qualification or translated source metadata. Exact query/ID expectations are in `case-ledger.json`.

Native result links carry query, access, provider, pagination, dataset and locale into coverage. Guided results use their declared page and separate `discoveryQ`/filter context from destination query parameters; the generic gateway opens source search with the existing query. Company record URLs retain that separate context without switching an official view to archive-only mode. Literal `q=all` survives URL updates. Inventory changes reset a later page to page one with an explanation. Coverage restores datasets and resources by ID, including a resource outside the first list page, using the read-only inventory metadata endpoint `GET /api/v1/resources/{resourceId}` without contacting its provider.

Coverage and playground consume bounded typed selector actions. Only schema/query tools and whitelisted selectors are accepted, with selected resource/dataset, parent file and explicit caller-parameter checks. A sheet retains its parent path/settings; choosing a different parent clears the old sheet, and selector changes clear incompatible projections. Restoring required source inputs preserves the explicit saved parameter values. URLs retain validated bounded selectors and contain no records, versions or continuations. Required provider examples remain placeholders, not inferred user input. Qualified weather shortcuts retain observation, units, source and date evidence.
