# mcp.hk wordmark

The logo is the full lowercase name `mcp.hk`, set in Public Sans Semibold (weight
600), with letter spacing of −0.025 em. Use the name alone, in one solid colour.

- Master artwork: `src/mcp_open_data_hk/web/logo.svg`. The letters are outlined
  vector paths, so rendering does not depend on installed fonts or network requests.
- Header size: 125 × 40 px. Preserve the SVG proportions and leave at least 4 px
  of clear space around it. Keep the artwork at least 95 px wide.
- Colour: forest green `#26694c` on light backgrounds, mint `#9cddb8` on dark.
- Browser icon: `src/mcp_open_data_hk/web/favicon.svg`. It stacks `mcp` above `.hk`
  in Public Sans Bold (700), retaining the full name within a square browser tab.
- Source: [Public Sans](https://github.com/uswds/public-sans), via
  [Google Fonts](https://github.com/google/fonts/tree/main/ofl/publicsans).
- Typeface licence: [SIL Open Font License](licenses/PublicSans-OFL.txt).

There is no separate symbol, monogram or decorative badge. Keep source agency names
and provider attribution separate from the wordmark.
