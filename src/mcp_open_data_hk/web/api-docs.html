First request

Public read access needs no mcp.hk account or API key. Source availability and request limits still apply.

  1. Start with a published district figure

    This request reads the Central and Western district’s published population statistics. It does not collect new source data.

  2. Copy and run the request

    Paste this command into a terminal, or open the JSON response.

  3. Read the value and its context

    Look for data.population and data.referencePeriod, then inspect provenance for the source and retrieval context. The reference year does not advance when you make a request.

HTTP / GET
curl -fsS 'https://mcp.hk/api/v1/districts/central-western/statistics'

Open JSON response
